Hello User! listen to your files

▸

2024

performance

python coding

sound design

▸

In this performace, audiences view their motherboard personified as a receptionist, live processing photofiles into printersounds. Each file gets dragged into a python script that transaltes each photo into 1s and 0s that each correspond to a printer sound. This process is projected live behind the character.

As each photo gets processed, the sounds lay over eachother creating a chaotic soundsscape, illustrating the overflow of files that we keep.
